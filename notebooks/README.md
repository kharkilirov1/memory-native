[Memory Native](../README.md) / Notebooks

[**Cached-KD workflow**](cached_kd_public.ipynb) walks through conversion, teacher caching,
recovery, selection and reloading the selected artifact using committed scripts.
Its default CPU smoke uses synthetic data to check the pipeline, not language-model quality.

For a donor run, supply the model and corpus explicitly and follow the provenance checks
in the notebook. See the [workflow tools](../scripts/README.md) and
[reproducibility guide](../docs/reproducibility.md).

Older Colab, Kaggle and 27B recovery recipes are preserved in the
[research archive](../research/notebooks/README.md).
