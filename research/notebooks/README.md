[Research](../README.md) / Notebooks

This directory preserves previous Colab and cloud-run recipes. The 27B notebook family
requires an external runner bundle that is not committed here. Names and historical
release labels do not establish that a workflow is currently reproducible.

For new work, use the [public cached-KD notebook](../../notebooks/cached_kd_public.ipynb),
which calls the committed conversion, cache and recovery tools.

Consult the [artifact manifest](../results/ARTIFACT_MANIFEST.md) and
[campaign preflight contract](../campaigns/PREFLIGHT_CONTRACT.md) before attempting an
archived run. Run directories remain append-only; retain existing checkpoints and logs.
